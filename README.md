# Student Management System (Java)

## 📌 Project Description
A console-based Java application to manage student records such as Student ID, Name, Course, Age, and Marks.  
The system supports CRUD operations, file persistence, and demonstrates core Java concepts learned during the internship.

## 🚀 Features
- Add Student Record
- View All Student Records
- Search Student by ID
- Update Student Record
- Delete Student Record
- Exit Menu

## 🛠 Technologies Used
- Java (JDK 17+)
- Collections (`ArrayList`, `HashMap`)
- File Handling (`BufferedReader`, `BufferedWriter`)
- Multithreading (`Thread`)

## 🎯 Java Concepts Demonstrated
- **OOP**: Classes, Objects, Constructors, `this`, `static`
- **Inheritance & Polymorphism**: Abstract class `Record`, subclass `Student`
- **Encapsulation**: Private fields with getters/setters
- **Abstraction**: Abstract class and `Manageable` interface
- **Exception Handling**: Try-catch for file I/O and input errors
- **Collections**: `ArrayList` for storing student records
- **File Handling**: Persistent storage in `students.txt`
- **Multithreading**: Auto-save thread running in the background
